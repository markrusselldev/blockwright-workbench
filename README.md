# Blockwright Workbench

One-click developer tools for block-theme work: clear caches and transients, rescan
patterns, and reset Site Editor database overrides that shadow your theme files. Off by
default; the admin-bar toolbar appears only in local or development environments, or when
explicitly enabled. Destructive tools require the `edit_theme_options` capability and confirm
before running.

**Install from WordPress.org:** https://wordpress.org/plugins/blockwright-workbench/
